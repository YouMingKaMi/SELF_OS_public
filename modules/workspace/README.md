# workspace

拥有自定义部门（`department`）和跨端定制配置（`workspaceConfig`）。每个账号通过固定 `WORKSPACE_CONFIG_ID` 读写一条配置，沿用 v1 命令和变更流。没有配置时按全功能预设展示。模块开关使用黑名单，首页、部门、发现和设置始终可用。快捷布局字段缺省或为空时由客户端使用本机默认布局。

`index.ts` 公开预设、功能键、内置部门常量和纯规则。iPhone 的对应入口是 `CouncilCore.WorkspaceRules`。根据实际开关与隐藏部门调用 `detectWorkspacePreset` 判定预设。应用预设时写入该预设的两个列表，保留别名与布局字段。

服务端验证开关和部门键，规范化别名 JSON，并依据首次出现的顺序去重列表。布局最多接收 40 项，修剪后单项最多 60 个 UTF-16 代码单元，空项丢弃。别名修剪后最多 40 个 UTF-16 代码单元。现有配置使用 `patch` 更新，传 `null` 可清除任意可选字段，空别名对象也会清除该字段。
